# Copperline glossary

- **Assignment**: A dispatch rule to implement for every incoming batch.
- **Batch**: One ordered input and its required ordered output.
- **Hands**: The single value carried by the courier; may be empty.
- **Floor**: Numbered storage tiles holding values or nothing.
- **Route**: The player's ordered instruction program.
- **Label**: A stable named destination attached to an instruction.
- **Certification**: Running a route against every assignment batch.
